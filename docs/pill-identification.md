# 알약 후보 검색 규칙

사진 추출기와 수동 개발 도구는 `PillObservation`을 전달하고, 검색기는 공식 카탈로그에서 비교 후보와 근거를 반환한다. 사진 추출과 후보 검색은 분리되어 있으며 검색 단계에서 AI가 약 이름을 결정하지 않는다. 구현은 [`pill-identification.ts`](../backend/src/pill-identification.ts), 제형 정책은 [`pill-form-policy.ts`](../backend/src/pill-form-policy.ts)에 있다.

## 입력 계약

현재 입력은 `pill-observation.v2`다. 제형·온전함·알약 수·겹침·품질·모양·색상과 앞뒤 면의 각인·분할선을 구조화한다. 과거 v1은 저장 자료를 재생하는 변환 경로로만 지원한다.

- 지원 대상은 온전한 정제·캡슐이다. 분말·과립·액상, 훼손·분할, 여러 알약·겹침과 판독 품질 부족은 비교 전에 별도 처리한다.
- 각 면의 `imprintCandidates`는 원문 판독 후보 최대 5개다. `imprintVisibility`의 `clear`, `partial`, `unreadable`을 구분한다.
- 글자가 없음을 직접 확인한 경우만 `noImprintObserved: true`다. 판독 실패나 공식 데이터 누락을 무각인으로 바꾸지 않는다.
- `scoreLine`의 `unknown`과 `none`도 구분한다. 보이지 않는 특징을 없다고 추정하지 않는다.
- 한 사진 쌍의 앞뒤는 같은 알약이어야 한다. 사진 쌍·손상·재촬영 게이트는 [`pill-photo-pipeline.ts`](../backend/src/pill-photo-pipeline.ts)에서 적용한다.

## 비교와 정렬

최소 한 면에 비어 있지 않은 문자 각인 일치 근거가 있어야 비교 후보 자격을 얻는다. 원문 각인을 보존하고, 서버가 제한된 `I/1`, `O/0` 등의 혼동 확장을 별도 근거로 기록한다. 확장량은 후보당 16개·면당 40개로 제한한다.

각인 근거가 외형 근거보다 우선한다. 알려진 모양·색상 불일치는 `conflicts`에 남기고 정렬에 반영하므로 색상 오분류 하나로 각인 근거가 있는 후보를 제거하지 않는다. 이것이 촬영 오차 보정이나 불일치 무시를 뜻하지는 않는다.

동일 품목코드에 공식 외형이 여러 개면 각 레코드의 양면을 한 쌍으로 유지한다. 서로 다른 외형의 앞뒤를 섞지 않으며 품목별로 묶어 보여준다. 점수 동률은 품목코드·레코드 기준으로 안정적으로 정렬한다. 입력 목록 순서가 결과를 바꾸지 않아야 한다.

## 결과 계약

| 결과 | 해석 |
|---|---|
| `candidates` | 현재 규칙을 통과한 공식 비교 후보; 확정 약이나 의학적 확률이 아님 |
| `heldCandidates` | 문자 근거 부족·공식 제형 미상 등으로 판단을 보류한 외형; `reviewReasons`를 함께 제공 |
| `needs_review` | 보류·불완전 관찰 등으로 추가 확인이 필요함; 처리 오류와 구분 |
| 재촬영 | 사진 품질·쌍·손상 조건을 통과하지 못해 후보를 제공하지 않음 |
| 정상 무결과 | 유효한 관찰·완전한 카탈로그로 검색했지만 조건에 맞는 후보가 없음 |
| 오류 | 목록 불완전·만료·외부 분석 실패 등으로 검색을 완료하지 못함 |

부분 판독 면이 있으면 정확 문자열이 일치하더라도 등급은 최대 `possible`이다. 비지원 공식 제형은 후보·보류 모두에서 제외한다. 비교·보류의 전체 건수와 반환 건수·잘림 여부를 구분하고 같은 품목이 양쪽에 있을 수 있음을 고려한다. 웹 결과는 그룹별 최대 10개이며 수동 CLI 제한과 구분한다.

카탈로그의 스키마·해시·완전성·최신성을 통과하지 못하면 검색을 중단한다. 검색은 복약 계획·일정·알림·복용 기록을 변경하지 않는다. 후보가 하나만 남아도 복용 허용으로 처리하지 않는다.

## 검증과 한계

합성 회귀 검사는 무각인/판독 실패 구분, 혼동 확장 근거, 부분 판독 등급, 외형 충돌, 안정 정렬과 오류를 검사한다. 공식 필드에서 관찰값을 복사한 예제는 자기 일관성 검사이며 사진 인식 정확도가 아니다. 실제 평가에는 실패한 holdout이 있으며 규칙 통과가 오인 방지를 보장하지 않는다. [평가 방법·결과](pill-photo-evaluation.md), [카탈로그 수집](pill-catalog.md), [웹 사진 처리](pill-photo-web.md)
