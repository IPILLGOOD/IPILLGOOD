# UI 기준 브랜치 복구

화면 기준은 `feature/new_work`의 `2dbb4fc09951d6a8cdfe93f13b5f4d21a323b867`이다. 통합 후 다른 브랜치의 화면 구조와 스타일이 적용된 부분을 이 기준으로 복구했다.

- 공통 레이아웃·내비게이션, 랜딩·로그인, 오늘 할 일·대시보드, 복용약·상세, 안부 확인, 프로필, 문서 등록에 원래 화면을 적용한다.
- 기본 문서 등록은 병명 입력 → 처방전 또는 약봉투 첨부 → 약별 검토 → 선택한 약 확정 순서다. 진단서 기능은 별도 등록 링크로 진입한다.
- `pages.css`, `design-refresh.css`, `refinement.css`는 기준 브랜치를 따른다. `experience-refresh.css`, `approved-patterns.css`, `landing-next.css`를 공통 레이아웃에 다시 연결하면 이 화면을 덮어쓸 수 있다.
- 이후 추가된 기능에 필요한 국소 스타일만 `feature-compatibility.css`에서 제공한다. 복용약 선택·좁은 화면의 보정은 이 파일에 둔다.

최신 메인의 서버 계약과 기능은 유지한다. 문서 분석의 Firestore 요청 최적화, 취소·재시도·중복 해결·검토에서 제외한 후보 넘기기, 약 등록의 검증된 선택값, 삭제 결과 표시, 약 설명 갱신, 임의 확정 질환 편집, 알약 사진 분석과 명시적으로 요청하는 영양 자료 검색을 연결한다. 페이지를 여는 것만으로 유료 영양 검색을 자동 실행하지 않는다.

브라우저 검증은 복구한 화면의 실제 입력·이동 방식으로 진행한다. 안부는 한 화면의 질문에 답하고, 모바일에서는 기본 메뉴로 이동하며, 문서 종류는 별도 등록 주소로 구분한다. 서버 권한, 동의, 데이터 저장·정정·삭제 및 재시도 검증은 유지한다.
