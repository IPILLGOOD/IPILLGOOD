# 화면별 UI 기준

문서 등록과 대시보드는 `feature/new_work`의 `2dbb4fc09951d6a8cdfe93f13b5f4d21a323b867`을 기준으로 유지한다. 나머지 화면과 공통 내비게이션은 Daniel Kim(`dkim1112`, 커밋 이름 Dongeun Kim)의 PR #143 `codex/ui-refresh` 작업을 통합한 메인 `305515e70e834e21a2184a9565c14f42df8184d5` 기준이다.

- 문서: 병명 입력 → 처방전 또는 약봉투 첨부 → 약별 검토 → 선택한 약 확정. 진단서는 별도 등록 링크로 진입한다.
- 대시보드: 기존 돌봄 달력, 복용 여부 기록·정정, 몸 상태 기록을 유지한다.
- 랜딩·로그인, 오늘 할 일, 복용약·상세, 영양, 안부, 프로필, 공통 메뉴: Daniel Kim의 UI를 사용한다. 모바일 빠른 기록, 약 넘김·페이지 표시, 단계별 안부 입력, 프로필 접기·펼치기를 포함한다.

`AppShell`은 문서·대시보드 본문에 `new-work-content`, 나머지 본문에 `experience-content`를 적용한다. `experience-refresh.css`와 `approved-patterns.css`의 본문 스타일은 `experience-content` 안에서만 적용한다. 공통 메뉴는 `experience-shell`로 유지한다. 문서·대시보드의 페이지별 기본 CSS는 두 기준 커밋에서 동일하므로 별도 복제하지 않는다. 두 화면의 `PageHeader`에는 `appearance="new-work"`를 지정한다.

최신 메인의 서버 기능은 유지한다. 문서 분석 요청 최적화, 취소·재시도·중복 해결·약별 검토, 검증된 약 등록, 알약 사진 분석 및 동의, 영양 자료 검색을 보존한다. 복용약 선택은 항목 ID로 관리해 선택한 약을 삭제해도 남은 약과 선택 표시가 일치한다.

브라우저 검증은 화면별 실제 입력 방식으로 진행한다. 문서의 병명 필수 입력·별도 진단서 진입, 안부 질문의 단계 이동, 프로필 그룹 열기, 모바일 빠른 기록과 약 넘김, 선택한 마지막 약 삭제 후 선택 유지 및 새로고침을 확인한다.
