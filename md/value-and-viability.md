# Value & Viability

## 사용자와 문제

1차 사용자는 여러 약을 복용하는 65세 이상 가족을 돌보는 보호자입니다. 병원에서 처방을 받은 뒤 보호자는 약의 목적, 실제 복용 여부, 몸 상태 변화와 다음 진료 질문을 서로 다른 메모와 기억에 의존해 관리합니다.

## 핵심 가치

> 처방전 한 장을 오늘의 복약 대시보드로 바꾸고, 매일의 짧은 답변을 다음 진료에 가져갈 기록으로 쌓는다.

성공 기준은 사용자가 설명 없이 다음 작업을 완료하는 것입니다.

1. 현재 복용약과 복용량·횟수·기간을 구분해 말할 수 있음
2. 1분 안에 복용 여부와 몸 상태를 기록함
3. 기록된 증상을 약의 원인으로 오해하지 않고 의료진 질문으로 전달함

## 운영 가능성

- 비식별 데모 데이터와 서버 시드로 반복 가능한 시연 제공
- 공식 의약품 데이터와 AI 설명 계층을 분리해 오류 범위 축소
- 원본 문서 미저장, Firestore 직접 접근 차단으로 초기 개인정보 노출면 축소
- 모바일 우선 UI와 큰 터치 영역으로 어르신 직접 응답 가능성 확보

개인 보호자용 기록 → 가족 공동 돌봄 → 약국 상담 준비 → 병원·돌봄 서비스 연계 순서로 확장합니다. 진단·처방 변경 제품이 아니라 공식 정보를 이해하고 관찰 기록을 전달하는 보조 도구의 경계를 유지합니다.
