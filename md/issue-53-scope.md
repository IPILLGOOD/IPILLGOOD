# #53: 최근 7일 조회·표시 보정

이번 브랜치는 오늘을 포함한 서울 달력 날짜 7일의 조회·표시만 수정한다. 원본 데이터, 복약 계획, 알림 일정과 저장 모델은 변경하지 않는다.

- 대시보드와 Care Report의 복약·증상 집계 및 시간축에 같은 기간 적용
- 응답이 없는 기간은 `기록 없음`, 실제 응답이 있고 완료가 없는 경우는 `0%`로 구분
- 전체 증상 일수를 어지러움으로 표현하지 않으며 반복 어지러움 안내도 기간 내 해당 증상만 사용
- 기간과 응답 기반 분모의 한계 표시, 시간축의 정렬 후 개수 제한
- 오래된 활성 복약은 현재 복용약 목록에서 제거하지 않음

이슈 전체를 종료하지 않는다. #78·#79·#89의 예정 회차 분모, append-only 관찰 추적, 승인된 지표 사전과 추가 지표 구현은 별도 선행 작업이다.

회귀 테스트: `npm test --workspace @care-atlas/front`의 `recent-care-records.test.mjs`. 서울 자정, 연말·윤년, 지연 응답, 무응답과 0%, 증상 유형, 원본 불변성을 확인한다.

## 확인한 결과

- 프런트 단위 테스트 48개·백엔드 테스트 90개, 타입 검사, 린트, 프로덕션 빌드 통과
- 격리 Firestore 에뮬레이터의 합성 데이터로 대시보드 50%·리포트 1/2회·증상 1일을 확인
- 기간 밖 복약·어지러움과 오래된 복약 시작은 시간축에서 제외하고, 오래된 활성 약은 현재 복용약 목록에 유지
- 빈 기간의 `기록 없음` 표시 확인
- 대시보드·리포트의 320/768/1024/1440px 가로 넘침 없음, 브라우저 오류 로그 없음
